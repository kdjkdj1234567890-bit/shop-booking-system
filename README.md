# 동네가게 예약 시스템

미용실 · 네일샵 · 맛집 같은 동네 자영업자를 위한 **온라인 예약 관리 시스템** 데모입니다.
손님은 전화 없이 1분 만에 예약하고, 사장님은 폰으로 예약 현황·매출·단골을 한눈에 봅니다.

## 왜 만들었는가

높은 가치는 느끼는 사람들에게 전달되어야 합니다.

동네 사장님들은 손님 한 분 한 분을 정성으로 대합니다. 그런데 전화 응대하느라
정작 손님 앞에서의 시간이 끊기기 일쑤였습니다. 밤이 되면 "오늘 예약이 몇 건이었지?"
정산 걱정이 밀려옵니다.

동네가게 예약은 그 걱정을 덜어주는 것에서 시작했습니다.
손님이 직접 예약하면 사장님은 일에만 집중하고,
밤에는 "오늘도 잘했어요"라는 마음으로 가게 문을 닫을 수 있게요.
핵심 메시지는 하나입니다 — **"밤에 정산 걱정 안 해도 돼요."**

여기에 쌓인 예약 기록과 단골 명단은 사장님의 재산입니다.
**이 데이터는 10년 후에도 사장님의 것입니다.**
자녀분이나 믿는 직원에게 가게를 물려주실 때("가게 이어받기"),
사장님이 쌓은 신뢰가 그대로 이어지도록 만듭니다.

우리는 사장님의 일을 세상이 알아주게 만듭니다.

## 실행 방법

```bash
bash run.sh
```

브라우저에서 접속:

- **손님용**: http://localhost:5000 — 가게 목록 → 예약 신청 → 내 예약 조회
- **사장님용**: http://localhost:5000/admin — 대시보드 · 메뉴 관리 · 예약 캘린더

종료는 터미널에서 `Ctrl+C`. (Flask가 없으면 자동으로 설치합니다. 별도 설정·외부 API 불필요)

## 타겟 고객

- **동네 미용실 · 네일샵 사장님** — 전화 예약 응대하느라 시술이 끊기는 게 가장 큰 pain. 예약제로 바꾸면 대기 손님 관리 + 노쇼 추적이 한 번에 해결됩니다.
- **동네 맛집 사장님** — 점심시간 줄 서는 손님을 예약으로 분산. 단체석 예약도 폼으로 받습니다.
- 공통점: 40~60대, 스마트폰은 쓰지만 PC는 잘 안 켜는 분들 → **모바일 반응형이 필수**라 모든 손님 화면을 모바일 우선으로 만들었습니다.

## 핵심 어필 포인트 (사장님 설득용)

1. **전화 응대 0건** — 손님이 직접 날짜·시간을 골라 예약 신청. 사장님은 확정 버튼만 누르면 됩니다.
2. **더블부킹 원천 차단** — 같은 시간대에 예약이 겹치면 시스템이 막습니다. 종이 장부의 실수 걱정 끝.
3. **돈이 보이는 대시보드** — 오늘 예약 수, 이번 주 매출 예상, 단골 고객 수(2회 이상 방문)를 자동 집계.
4. **노쇼 관리** — 노쇼 버튼 하나로 기록. 상습 노쇼 손님을 파악할 수 있습니다.
5. **설치·가입비 없음** — 가게 메뉴(시술명·소요시간·가격)만 등록하면 바로 사용. 영업시간에 맞춰 예약 시간대가 자동 생성됩니다.

## 기능 목록

### 손님용
| 기능 | 설명 |
|---|---|
| 가게 목록 | 카테고리·영업시간·연락처와 함께 가게 탐색 |
| 예약 신청 | 서비스 선택 → 날짜 선택 → 실시간 빈 시간대 조회 → 이름+연락처 입력 |
| 중복 예약 방지 | 같은 시간대 겹치는 예약은 서버에서 트랜잭션으로 차단 (동시 신청도 안전) |
| 내 예약 조회 | 예약 시 입력한 연락처로 조회, 본인 예약 직접 취소 가능 |
| 입력 검증 | 잘못된 연락처·지난 날짜·영업시간 외 선택 시 친절한 안내 (에러 화면 노출 없음) |

### 사장님용
| 기능 | 설명 |
|---|---|
| 대시보드 | 오늘 예약 수 · 이번 주 매출 예상 · 단골 고객 수 · 확정 대기 · 누적 노쇼 |
| 서비스 메뉴 관리 | 등록/수정/삭제, 노출 켜기·끄기 (진행 중 예약이 있는 메뉴는 삭제 방지) |
| 예약 캘린더 | 날짜별 30분 단위 시간대 현황 + 예약 목록, 전날/다음날 이동 |
| 상태 관리 | 예약대기 → 확정 → 취소/노쇼. 이미 처리된 예약의 중복 처리는 차단 |

## 기술 스택

- Python Flask 3 + SQLite (파일 DB, 별도 DB 서버 불필요)
- 순수 HTML/CSS/JS — 외부 CDN·외부 API·유료 서비스 사용 없음
- 모바일 반응형 (손님 화면 520px 우선, 관리자 1080px 와이드)

## 화면 구성

| 주소 | 화면 |
|---|---|
| `/` | 짜증 오프닝 + 업종 선택 + 손님용 가게 목록 (첫 화면) |
| `/briefing` | 사장님 오늘 브리핑 — 오늘 예약·이번 주 들어올 돈·존엄 메시지·루틴 인사 |
| `/shop/1` | 가게 상세 + 예약 신청 (손님용) |
| `/my` | 내 예약 조회 (손님용) |
| `/admin` | 사장님 대시보드 |
| `/admin/bookings` | 예약 캘린더 + 상태 관리 |
| `/admin/services` | 메뉴 관리 |
| `/value` | 가치 계산기 + 경쟁사 비교표 + ROI ("월 3만원으로 월 ○○만원 지키세요") |
| `/report` | 월간 리포트 ("이번 달 벌어다준 돈") + 단톡방 공유 |
| `/growth` | 옆 가게 소개 리워드 + FOMO + 성장 시뮬레이터 |
| `/about` | 소개 — 레거시 철학 + 일곱 가지 약속 + 사명 선언문 |
| `/badge` | 입소문 배지 ("이 가게는 동네가게 예약 시스템을 사용합니다") |

## 사장님 심리 설계

- **짜증 모먼트 오프닝**: 첫 화면은 "전화로 예약 받다가 현장 일 2시간 날리셨죠?"로 시작 → "이제는 이렇게"
- **감정적 해방**: "밤에 정산 걱정 안 해도 돼요"
- **업종 프리셋**: "어떤 가게세요?" → 청소업체/미용실·네일샵/이사·용달 선택 시 메뉴·용어·가격대 변경
- **도파민 대시보드** (`/briefing`): 오늘 예약 N건, 이번 주 들어올 돈, 새 예약 시 "새 손님이 왔어요! 🎉" 축하
- **벤치마크**: "우리 동네 미용실은 전화 응대로 주 6시간" vs "지금 0시간" 비교 막대
- **매일 루틴**: 아침 "오늘도 힘내세요 😊" / 저녁 "오늘 수고하셨어요" / 월말 "사장님 최고예요"
- **존엄**: "오늘 5분이 사장님 덕분에 예뻐지셨어요" — 돈이 아니라 사람을 셉니다
- **정직**: 숫자를 부풀리지 않습니다. 가정은 가정이라고 밝힙니다
